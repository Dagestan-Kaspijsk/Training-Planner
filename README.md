Training Planner

## Описание проекта

Графическое приложение для планирования и учёта тренировок. Позволяет добавлять новые тренировки с указанием даты, типа и длительности. Данные сохраняются в файл формата JSON. Реализована фильтрация по дате и типу тренировки.

## Инструкция по запуску

1. Убедитесь, что у вас установлен **Python 3.x**.
2. Скачайте или клонируйте этот репозиторий.
3. Запустите файл `main.py`:
   ```
   python main.py
   ```
4. Приложение откроется в новом окне.

## Функционал приложения

- **Добавление тренировки:**
  Заполните поля «Дата», «Тип тренировки» и «Длительность» и нажмите кнопку «Добавить тренировку». Данные будут сохранены и отображены в таблице.
- **Фильтрация:**
  Введите дату или тип тренировки в соответствующие поля и нажмите «Применить фильтр». В таблице отобразятся только подходящие записи.
- **Сохранение данных:**
  Все тренировки автоматически сохраняются в файл `trainings.json` при добавлении новой записи. При следующем запуске данные будут загружены.

## Примеры использования

**1. Добавление тренировки**
*   **Дата:** `2024-05-01`
*   **Тип:** `Кардио`
*   **Длительность:** `45`
*   Нажмите «Добавить тренировку».
*   *Результат:* Запись появится в таблице и будет сохранена в JSON.

**2. Фильтрация по типу**
*   В поле «Тип» введите: `силовая`.
*   Нажмите «Применить фильтр».
*   *Результат:* В таблице останутся только тренировки с типом «Силовая» (поиск регистронезависимый).

**3. Фильтрация по дате**
*   В поле «Дата» введите: `2024-05-01`.
*   Нажмите «Применить фильтр».
*   *Результат:* Покажутся все тренировки за 1 мая 2024 года.

**4. Сброс фильтра**
Просто удалите текст из полей фильтрации и нажмите кнопку снова — отобразится полный список.
